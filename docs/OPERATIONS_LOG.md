# Operations Log

One entry per real incident or notable operational event. Be specific and blameless. Entries like these are your best interview material.

## Template

### YYYY-MM-DD: <short title>
- **Detected by:** (alert / canary / user report / me noticing)  **Time to detect:**
- **Impact:** (who/what, for how long, how many jobs)
- **Timeline:** (UTC, bullet per step)
- **Root cause:** (the real one: keep asking "why")
- **Fix:** (what restored service)
- **Prevention:** (code/test/alert/runbook change, with link to the commit)
- **What went well / what did not:**
